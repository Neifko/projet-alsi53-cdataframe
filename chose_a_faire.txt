A faire / Problèmes connus (à corriger ou implémenter) :
1) Initialisation et invariants
   - Après insertion de valeurs, marquer l'index invalide (validIndex = false) si existant.

2) Vérification stricte des types
   - Implémenter vérification du ColumnType dans Column::insertValue et CDataFrame::insertRow pour empêcher l'insertion d'un variant d'un autre type que la colonne.
   - Décider politique pour conversions numériques implicites (autoriser/convertir ou rejeter).

3) Comparaison robuste entre variantes
   - Remplacer les comparaisons directes entre std::variant par une fonction utilitaire compareValues qui :
     - Gère les conversions numériques (int/float/double...) de façon sûre,
     - Compare chaînes uniquement avec chaînes,
     - Définit un ordre stable pour mixed-type comparisons si nécessaire,
     - Evite comportement indéfini quand alternatives diffèrent.
   - Utiliser cette utilitaire dans Column::sort, searchValue, countValuesGreaterThan/..., etc.

4) Recherche binaire / index
   - Corriger/fiabiliser Column::searchValue : comparator pour lower_bound doit être cohérent avec l'ordre défini par compareValues et tenir compte de sortAscending.
   - Mettre à jour updateIndex() pour recalculer l'index si invalid (ou fournir une API explicite pour rebuildIndex).

5) CSV I/O et parsing
   - Implémenter loadFromCSV(filename, types), loadFromCSVAuto(filename) (détecte types), saveToCSV(filename).
   - Ajouter utilitaires parseLine / parseDataLine pour parser correctement CSV (gestion quotes, types, valeurs NULL).
   - Ajouter tests d'import/export CSV.

6) API manquante / ergonomie
   - Implémenter operator[](size_t) et operator[](const std::string&) pour CDataFrame (accès direct aux colonnes).
   - Surcharger operator<< pour CDataFrame et éventuellement Column (affichage via flux).
   - Ajouter printHeader(std::ostream&) overload si besoin par la documentation.

7) Support OBJECT / std::any (optionnel)
   - Si besoin, ajouter ColumnType::OBJECT et std::any dans ColumnValue et gérer sérialisation / comparaison (complexe).

8) Gestion des erreurs / exceptions
   - Uniformiser les exceptions/messages d'erreur (out_of_range, invalid_argument).
   - Eviter prints directs dans les méthodes de bibliothèque — préférer retours d'erreur / exceptions et laisser le caller décider de l'affichage.

9) Tests et couverture
   - Ajouter tests unitaires ciblant :
     - insertion de types incorrects,
     - sorts stables et sync multi-colonnes,
     - searchValue edge-cases,
     - CSV import/export round-trip,
     - operator[] et operator<<.
   - Ajouter cas limites (colonnes vides, lignes incomplètes, valeurs NULL).

10) Documentation
   - Compléter commentaires Doxygen dans headers (CDataFrame.h, Column.h, ColumnValue.h).
   - Documenter comportement attendu pour conversions de types et NULL.

11) Petites améliorations / optimisations
   - Revoir usage de shared_ptr vs unique_ptr pour colonnes (propriété unique du dataframe → unique_ptr possible).
   - Ajouter parse/format helpers pour normaliser affichage (largeur colonnes, alignement).
   - Considérer l'ajout d'une structure d'index par nom pour accès rapide aux colonnes (unordered_map<string,size_t>).
